# 完整迭代总结

## 应用定位
「AI 文学锐评」写作工具：写作 → AI 深度解读（文内批注、五维评分、相似作家、续写）→ 导出 PDF/分享图。前端 React 18 + Zustand + Slate，后端 Vite dev proxy + 独立 Node API server（`api/review.js`，讯飞星辰 MaaS 免费 Qwen 模型）。

---

### 基础设施（此前遗漏）
- **双部署通道**：
  - Vercel 生产（`bidazi.cloud` / `biedazi-react.vercel.app`）：项目 `biedazi-react`，`.vercel` 元数据 + 根 `vercel.json`（`/api/*` 路由），生产环境变量 `XFYUN_API_KEY`/`XFYUN_MODEL`
  - GitHub Pages（`.github/workflows/deploy.yml`）：push main 自动构建 `dist` 部署，`vite.config.js` 按 `GITHUB_PAGES` 切换 base
- **技能体系**：`.agents/skills` 锁定 9 个技能（emilkowalski 动画审计 5 个、产品管理 4 个），v11 动画重构即源自此
- **本地 API**：`scripts/dev-server.mjs` 读取 `.env`，CORS 全开，3000 端口

### 本次会话完整工作（1.00c，未部署）
1. **水彩飞溅右→左 + 浸润保持**：色斑由 `clip-path` 展开改为 `translateX(26vw)→0` 真正"从右侧甩入向左飞落"（GPU transform），整幅色带 `watercolor-sweep` 由右向左铺开；动画约 2s 后整层沉降为 0.34 持久底色（之前完全淡出），符合"浸润后不消失"
2. **全站纸张质感**：`App.jsx` 新增 `.paper-grain`（SVG feTurbulence 细噪点 180px 平铺、multiply、z-85）+ `.paper-vignette`（中心微亮四角微沉光晕、z-86）两层叠加，覆盖所有面板之上（pointer-events-none）
3. **AI 分析动画水墨化**：`ThinkingProcess` 移除硬边雷达 ping 环与旋转射线，改三层 `ink-bleed` 水墨晕染环（radial-gradient 洇开扩散）+ 中心 `ink-breathe` 墨渍呼吸；底部新增 `brush-sweep` 毛笔扫过进度条；步骤配色由绿色改为墨色；整体套 `font-serif-cn` 衬线字体呼应纸感
4. **讯飞 3000 业务错误修复**：星辰 MaaS 在 HTTP 200 时 body 也可能带 `code != 0`（如 3000），原代码只在 `!response.ok` 时处理 → 误报"AI 返回为空"。`callXfyun` 现在先解析 body 并拦截 `data.code !== 0`（含 3000/3004/3005/4002/4003 标记 retryable）+ OpenAI 风格 `error.message`；handler 重试循环改为对 retryable 错误（含瞬时 3000、5xx、429）也重试 3 次温度，仅 401/403 配置类错误直接抛
5. **验证**：build 通过；Playwright（v3 脚本）确认 `.paper-grain/.paper-vignette` 存在、splash 层 4 色斑 + sweep clip 右→左 + 浸润后 opacity 沉降 0.34 保留、`hasFilterSvg` 真；v2 脚本回归下边栏字号（author 16/work 13/reason 13/pct 16/metaphor 22）与布局（bar 400、无溢出）不变
6. **修复"分析失败/AI 分析失败"TDZ 崩溃（关键）**：根因是 `api/review.js` 中 `bestQuote` IIFE 在 `const annotations` 声明之前就访问 `annotations[0]`（历史遗留，`return annotations[0]?.quote || best || ...`），模型给出的 bestQuote 一旦与原文句子匹配不上（`bestScore < 6`）就走兜底分支 → `Cannot access 'annotations' before initialization` ReferenceError，被外层 catch 包装成"AI 分析失败/请检查网络或 API 配置"。修复：把 `bestQuote` 计算移到 `annotations` 构建之后（放在 `normalizeAuthors` 之后）。排查中还确认了本地 `analyzeTextAPI` 的"AI 分析失败"默认文案会在代理 502/非 JSON 响应时出现（本次只是本地 dev-server 未启动所致）
