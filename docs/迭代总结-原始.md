# 完整迭代总结

## 应用定位
「AI 文学锐评」写作工具：写作 → AI 深度解读（文内批注、五维评分、相似作家、续写）→ 导出 PDF/分享图。前端 React 18 + Zustand + Slate，后端 Vite dev proxy + 独立 Node API server（`api/review.js`，讯飞星辰 MaaS 免费 Qwen 模型）。

  - Vercel 生产（`bidazi.cloud` / `biedazi-react.vercel.app`）：项目 `biedazi-react`，`.vercel` 元数据 + 根 `vercel.json`（`/api/*` 路由），生产环境变量 `XFYUN_API_KEY`/`XFYUN_MODEL`
  - GitHub Pages（`.github/workflows/deploy.yml`）：push main 自动构建 `dist` 部署，`vite.config.js` 按 `GITHUB_PAGES` 切换 base
- **技能体系**：`.agents/skills` 锁定 9 个技能（emilkowalski 动画审计 5 个、产品管理 4 个），v11 动画重构即源自此
